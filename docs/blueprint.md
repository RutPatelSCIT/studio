# **App Name**: ApnaStocks Simplified

## Core Features:

- Stock News Aggregation: Aggregate news articles from various sources related to the Indian stock market.
- Market Data Display: Display key market indices (e.g., Nifty, Sensex) and individual stock data (prices, charts) in a clear format.
- Personalized News Feed: Uses AI as a tool to provide users with personalized stock news based on user preferences, search history and selected interests.
- Real-time Stock Quotes: Provide real-time or near real-time stock quotes and price updates.
- Watchlist Functionality: Allow users to create and manage a watchlist of stocks they are interested in.

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082), suggesting sophistication and expertise in finance.
- Background color: Very light grey (#F5F5F5), for a clean, uncluttered look, not distracting from content.
- Accent color: Violet (#8F00FF) for interactive elements, and important highlights.
- Body and headline font: 'Inter', a sans-serif font that promotes a modern and easily readable experience across all devices.
- Use simple, geometric icons to represent stock-related actions (e.g., adding to watchlist, viewing details).
- Emphasize a clean and structured layout, using a grid system to organize financial data and news articles.
